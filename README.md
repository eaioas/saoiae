# IP Info — приложение для меню-бара macOS

Маленькое приложение, которое живёт в меню-баре (иконка 🌐) и показывает:

- внешний **IP-адрес** (клик по кнопке рядом — скопировать);
- **страну** с флагом и **город**;
- **провайдера**;
- **скорость интернета**: скачивание, отдача и пинг.

Данные обновляются **только по кнопке ⟳** в левом нижнем углу панели.
Приложение само добавляет себя в автозапуск при первом старте; выключить можно в меню ⚙.

Требования: macOS 13 Ventura или новее.

## Откуда берутся данные

| Что | Источник |
|---|---|
| IP, страна, город, провайдер | [ipwho.is](https://ipwho.is), запасной — [ipapi.co](https://ipapi.co) |
| Скорость | встроенная утилита macOS `networkQuality`, запасной — speed.cloudflare.com |

Замер скорости занимает около 30 секунд и нагружает канал, поэтому он запускается только по кнопке.

## Установка

### Вариант 1 — готовая сборка из GitHub Actions

1. Откройте вкладку **Actions** репозитория → последний успешный запуск **Build** → скачайте артефакт **IPInfo**.
2. Распакуйте архив (внутри ещё один `IPInfo.zip` — его тоже), перенесите `IPInfo.app` в «Программы».
3. Приложение подписано без сертификата разработчика, поэтому macOS его заблокирует. Снимите карантин:
   ```bash
   xattr -dr com.apple.quarantine /Applications/IPInfo.app
   ```
   или откройте **Системные настройки → Конфиденциальность и безопасность → «Всё равно открыть»**.
4. Запустите `IPInfo.app` — в меню-баре появится 🌐.

### Вариант 2 — собрать самому

Нужны Command Line Tools (`xcode-select --install`) или Xcode.

```bash
git clone <этот репозиторий>
cd saoiae
./build.sh install
```

Скрипт соберёт `build/IPInfo.app`, скопирует его в `/Applications` и запустит.

## Автозапуск

При первом запуске приложение регистрирует себя в «Объектах входа» (`SMAppService`).
Включить или выключить: ⚙ → «Запускать при входе». Если macOS попросит подтверждение —
**Системные настройки → Основные → Объекты входа**.

Важно: автозапуск привязан к месту, где лежит приложение, поэтому держите его в `/Applications`.

## Структура

```
Package.swift                     — Swift Package
Resources/Info.plist              — LSUIElement (без иконки в Dock)
Sources/IPInfo/
  IPInfoApp.swift                 — точка входа, MenuBarExtra
  ContentView.swift               — панель
  InfoModel.swift                 — состояние и обновление
  GeoService.swift                — IP / страна / город / провайдер
  SpeedTestService.swift          — замер скорости
  LaunchAtLogin.swift             — автозапуск
  Models.swift                    — модели, ошибки, HTTP
build.sh                          — сборка .app
.github/workflows/build.yml       — сборка на macOS в GitHub Actions
```
