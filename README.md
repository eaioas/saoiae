# MenuHider

Программа для macOS, которая прячет лишние иконки в menu bar.

- Иконка программы — шеврон `⌄` в menu bar.
- Иконки левее разделителя `│` скрываются; клик по `⌄` показывает/прячет их.
- Правый клик по `⌄` — меню: автозапуск, подсказка, выход.
- Запускается вместе с маком (включается автоматически при первом запуске).
- Нет иконки в Dock.

Требования: macOS 13 Ventura или новее.

## Сборка

Нужен Xcode (или Command Line Tools со Swift 5.9+).

```bash
./scripts/build-app.sh
open dist/MenuHider.app
```

Для автозапуска перенесите `dist/MenuHider.app` в `/Applications` и запускайте оттуда.

Готовый `.app` также собирается на GitHub Actions при каждом пуше —
его можно скачать во вкладке **Actions → Build → Artifacts**.

Для разработки можно открыть `Package.swift` в Xcode и запускать оттуда
(в этом режиме не работает только автозапуск — он требует собранного `.app`).

## Как пользоваться

1. Нажмите `⌄` — появится черта `│`.
2. Зажмите `⌘` и перетащите ненужную иконку левее черты.
3. Нажмите `⌄` ещё раз — иконки левее `│` скроются.
