# LayoutFix ⇄

Фоновая утилита для macOS. Исправляет текст, набранный не в той раскладке:
`ghbdtn` → `привет`, `руддщ` → `hello`.

Живёт в строке меню (значок **⇄**), в Dock не появляется.

## Возможности

| Режим | Как работает |
|---|---|
| **Хоткей** (по умолчанию `⌥Space`) | Есть выделение — конвертируется выделенный текст. Выделения нет — последнее набранное слово. Повторное нажатие возвращает как было. |
| **Автоисправление** (включается в меню) | После пробела проверяет слово. Если оно набрано в неправильной раскладке, заменяет его. |

Ещё:

* после исправления раскладка переключается сама (можно отключить);
* если отменить автоисправление хоткеем, слово попадёт в исключения и больше не будет исправляться;
* ссылки, почта, пути, слова с цифрами и `_` не трогаются;
* в терминалах, IDE и менеджерах паролей автоисправление выключено (список `excluded_apps`);
* поддерживаются обе русские раскладки: «Русская – ПК» и стандартная «Русская» Apple. Нужная определяется сама.

Слово проверяется системной проверкой орфографии macOS (русский и английский). Если слова нет
в словаре, в ход идёт эвристика по буквосочетаниям: `cjdctv` → `совсем`.

## Установка

Нужен `python3`. Он есть в Xcode Command Line Tools (`xcode-select --install`) или ставится через Homebrew.

```bash
git clone <этот репозиторий> ~/LayoutFix
cd ~/LayoutFix
./install.sh
```

Скрипт создаёт окружение в `~/.layoutfix/venv`, ставит зависимости и регистрирует автозапуск
(LaunchAgent `com.layoutfix.agent`). После этого приложение сразу запускается.

> Папку с репозиторием после установки не перемещайте: автозапуск ссылается на `main.py` в ней.

### Разрешения

При первом запуске macOS запросит два разрешения
(**Системные настройки → Конфиденциальность и безопасность**):

1. **Универсальный доступ** (Accessibility) — чтобы перехватывать хоткей и печатать исправленный текст;
2. **Мониторинг ввода** (Input Monitoring) — чтобы видеть набираемые слова.

Если Python не появился в списке, добавьте его кнопкой «+». `install.sh` в конце выведет путь.
Пока разрешений нет, значок выглядит как **⇄!**. Как только разрешения выданы, приложение их подхватит.

## Настройки

В меню можно переключить автоисправление и автопереключение раскладки, сменить хоткей
и включить или выключить запуск при входе. Остальное лежит в файле
`~/Library/Application Support/LayoutFix/config.json`. Открыть его можно пунктом меню
«Открыть файл настроек», после правки выберите «Перечитать настройки».

```json
{
  "hotkey": "alt+space",
  "auto_correct": false,
  "switch_layout": true,
  "ru_variant": "auto",
  "min_word_length": 3,
  "exclusions": ["ghbdtn"],
  "excluded_apps": ["com.apple.Terminal", "com.googlecode.iterm2"]
}
```

* `hotkey` — модификаторы `cmd`, `ctrl`, `alt`, `shift` плюс клавиша: буква, цифра, `space`, `f1`–`f15`;
* `ru_variant` — `auto`, `pc` («Русская – ПК») или `mac` («Русская»);
* `excluded_apps` — bundle ID приложений, где автоисправление не работает. Узнать ID можно командой
  `osascript -e 'id of app "Safari"'`.

## Консоль

```bash
~/.layoutfix/venv/bin/python main.py --convert "ghbdtn, rfr ltkf&"   # приветб как дела?
~/.layoutfix/venv/bin/python main.py -v                              # запуск с подробным логом
```

Лог: `~/Library/Logs/LayoutFix.log`.

## Удаление

```bash
./uninstall.sh           # оставить настройки
./uninstall.sh --purge   # удалить и настройки, и лог
```

## Разработка

Логика конвертации и распознавания не зависит от macOS. Тесты можно запускать где угодно:

```bash
pip install -r requirements-dev.txt
python -m pytest
```

| Файл | Назначение |
|---|---|
| `layoutfix/mapping.py` | таблицы клавиш QWERTY ⇄ ЙЦУКЕН |
| `layoutfix/detector.py` | решает, набрано ли слово в неправильной раскладке |
| `layoutfix/tracker.py` | буфер набираемого слова |
| `layoutfix/service.py` | логика хоткея и автоисправления |
| `layoutfix/macos.py` | CGEventTap, эмуляция нажатий, буфер обмена, Accessibility, переключение раскладки |
| `layoutfix/app.py` | меню в строке состояния (rumps) |
| `layoutfix/autostart.py` | LaunchAgent |

## Ограничения

* Если печатать очень быстро, пока идёт автозамена, символы могут перемешаться.
* В полях ввода паролей (Secure Input) macOS не передаёт нажатия, там утилита не работает.
* В приложениях без поддержки Accessibility выделение читается через `⌘C`. Буфер обмена
  после этого восстанавливается.
